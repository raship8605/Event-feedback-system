# Event Feedback System

A simple REST API built with Django & Django REST Framework to collect and manage event feedback.

## Features

- Create and manage events
- Collect feedback with ratings (1-5 stars) and comments
- View average ratings automatically
- See rating distribution analytics
- Simple token authentication for organizers
- Admin panel for easy management
- Public feedback submission (no login required)

## Tech Stack

- Backend: Django 5.x
- API Framework: Django REST Framework (DRF)
- Database: SQLite (default, can switch to PostgreSQL)
- Authentication: Token-based authentication
- CORS: django-cors-headers
